# Projeto Mic-1

Trabalho de Arquitetura de Computadores II (UFPB), da professora Sarah Pontes Madruga.
A ideia é simular a Mic-1 em Python, uma etapa de cada vez.

Grupo:
- Davi Araujo Alves
- Davi Ramos Soares
- Rafael Ramalho Pessoa Albuquerque de Brito

## Pastas

- `etapa1`: a ULA
- `etapa2`: a ULA com deslocador (tarefa 1) e os registradores (tarefa 2)

## Para rodar

Entra na pasta da etapa e roda o programa com o Python.

Etapa 1:

    python ula.py

Etapa 2:

    python etapa2_tarefa1.py
    python etapa2_tarefa2.py

Cada programa lê o arquivo de instruções que está na própria pasta e gera um log em `.txt`.
